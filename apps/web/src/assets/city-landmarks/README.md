# 城市地标素材

把地标线稿保存到本目录，文件名使用城市中文名，例如 `北京.png`、`杭州.svg`、`成都.webp`。支持 `.svg`、`.png`、`.webp`（小写扩展名），不读取子目录。同一个城市存在多种格式时，优先使用 SVG，其次 PNG、WebP。

- 页面按完整目的地名匹配（忽略首尾空格和末尾的“市”）。例如“北京市”匹配 `北京.svg`；“北京、天津”不会误用北京地标。
- 开发模式保存后刷新页面即可；正式部署需要重新构建 `npm run build -w apps/web`。
- 没有文件或文件加载失败时，继续显示居中的城市文字，不产生外网图库请求。
- 选择透明底、单色线稿，推荐正方形或接近正方形。SVG 应有 `viewBox`；PNG/WebP 必须有真实透明通道。页面将不透明笔画统一染成封面色；白底或画在图片中的棋盘格也会变成色块。
- AI 生成的白底黑色线稿需先去白底，导出透明 PNG/WebP；仅改扩展名或保存为 PNG 不会自动变透明。目前 `北京.png` 是用户提供的透明天坛线稿。
- 白底 PNG 可以跑 `npm run assets:transparent` 批量转透明（默认处理本目录，也可传目录参数 `node scripts/to-transparent.mjs <dir>`）。规则是「所有近白像素变透明、线条变黑」，已含透明像素的图会自动跳过，不会重复处理。
- 去掉大面积留白，线条不要太细；优先下载同一作者的系列，让各城市风格一致。移除脚本、外部图片、字体等依赖，保留独立矢量路径。
- 保存时记录作者、素材详情页和授权条件到 `SOURCES.md`。需要署名的素材应同时按作者要求在产品中提供署名；仅记录在文件内不一定满足要求。

免费来源与搜索关键词见仓库 `docs/CITY_LANDMARK_ASSETS.md`。
