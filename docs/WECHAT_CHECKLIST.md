# 微信内置浏览器真机实测清单（Phase D2 / R12）

> 前置：站点已通过 HTTPS 部署（Caddy），微信中打开站点 URL。

## 核对项

| # | 项目 | 操作 | 预期 | 结果 |
|---|---|---|---|---|
| 1 | 注册/登录 | 邀请码注册 → 退出 → 登录 | 会话保持，无白屏 | ☐ |
| 2 | SSE 生成进度 | 新建行程 → 观察三阶段时间线 | 事件持续推送不断流（Caddy `flush_interval -1` 生效） | ☐ |
| 3 | 切后台恢复 | 生成中切出微信再切回 | EventSource 自动重连，进度不丢（Last-Event-ID 重放） | ☐ |
| 4 | 地图手势 | 编辑器切「地图」页签，单指拖动/双指缩放 | 不与页面滚动冲突，标记可点出 Popup | ☐ |
| 5 | **长图保存（主场景）** | 导出 → 长图 PNG | 弹出「长按图片保存」引导层；长按可存相册/转发 | ☐ |
| 6 | JSON 导出 | 导出 → JSON 备份 | 微信可能拦截下载——若失败属已知限制，提示用户到系统浏览器操作（记录实际表现） | ☐ |
| 7 | 打印 | 导出 → 打印 / PDF | 微信内多半无打印能力，确认不白屏、可返回（记录实际表现） | ☐ |
| 8 | 输入体验 | 表单填写（日期/数字/多选 chips） | 键盘类型正确，弹出不遮挡输入框 | ☐ |
| 9 | 刷新恢复 | 生成中下拉刷新页面 | 恢复进度或直达结果页 | ☐ |
| 10 | 分享卡片 | 右上角「···」→ 发送给朋友 | 标题/链接正常（后续可加 og 标签优化） | ☐ |

## 已内置的兜底

- 长图：微信 UA（MicroMessenger）下**不走 download 属性**，直接展示「长按保存」引导层（`ExportMenu.tsx`）。
- SSE：断线由浏览器 EventSource 自动重连 + 服务端 Last-Event-ID 重放；刷新由 sessionStorage + 任务快照恢复。
- 若第 6/7 项确认不可用：v1.1 考虑「复制 JSON 到剪贴板」与「引导系统浏览器打开」的替代路径。
