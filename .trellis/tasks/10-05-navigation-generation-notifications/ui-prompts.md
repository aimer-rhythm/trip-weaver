# 基于现有产品的导航与通知 UI 提示词

日期：2026-10-05。以下是设计提示词，并非已实现界面；保留现有主体，只展示此次导航、生成返回和站内通知提案。每次使用公共提示词加一个场景，独立出图。

## 公共提示词

```text
基于现有旅行规划产品 TripWeaver 设计顶部导航与站内通知改版。保留现有页面主体、真实功能和中文文案。

视觉：浅蓝背景 #EEF3FD、品牌蓝 #2F6BF3、深蓝文字 #16325C，少量蓝紫渐变，磨砂白胶囊导航，细白色边框与轻阴影。导航和操作文字用清晰中文无衬线字体；旅行手册标题、手写副标题及生成页标题保留现有字体风格，不统一替换。

桌面顶部导航从左到右：现有波浪形 Logo、首页、我的行程；右侧按状态显示“杭州 · 生成中”，再放铃铛图标与退出图标。
只显示 Logo，不显示中英文品牌名。首页与我的行程保持文字，当前页面有淡蓝选中态。通知和退出均只用线性图标，图标线宽统一，点击区域充足。有未读消息时铃铛右上角只显示小红点，无数字；点击铃铛展开通知面板。无进行中任务时收起生成入口。

仅增加本轮讨论的导航、返回生成进度及站内通知界面。个人资料与设置入口移除。不新增账号头像、消息计数、营销模块、统计仪表盘、酒店机票预订、订单、社区或会员功能。

输出为正视角高保真产品界面，中文准确清晰，不使用设备外壳、透视展示、水印或画布外说明文字。每个场景独立生成一张图。
```

## 场景一：首页，后台正在生成

```text
画布 1440×900，保留当前首页布局。
左上主标题“想去哪座城市？”，副标题“让每一次出发，都有专属的旅行方案”。
主体为中国地图、省界、城市点位与当前城市选中效果；可规划城市点位与背景点区分，保持参考界面的地图造型和位置。
底部保留磨砂白规划胶囊，四段依次为“目的地”“出行日期”“节奏与同行”“偏好与出行”，右端为现有圆形指南针操作按钮。每段展示摘要，保留向上展开面板的结构。
顶部“首页”选中，右侧显示“杭州 · 生成中”，铃铛无红点，通知面板关闭。
表现用户已经离开生成页回到首页，能从导航重新打开原任务。不将首页替换成旅行推荐列表或大图营销页，不添加第二个并发生成入口。
```

## 场景二：现有生成页

```text
画布 1440×900，保留当前生成页面的旅行手账风格。
标题“正在为你编织 杭州 的 3 天旅程…”。
左侧为三阶段里程碑小径，名称严格使用“发现好去处”“安排每日路线”“完善旅程细节”。第一阶段完成，第二阶段进行中，第三阶段等待。
右侧保留现有真实景点照片、白色相纸边框、中文地点说明构成的扇形拍立得卡片。
底部保留已用时间与“取消生成”，不显示虚构百分比或模型运行数据。
顶部显示新的 Logo、首页、我的行程、杭州 · 生成中、铃铛和退出图标；生成入口有当前位置状态。
补充一行轻量说明“你可以先去看看其他行程，生成完成后会在站内通知你。”
保留整体布局和图片表达，仅展示新的导航和可离开提示。
```

## 场景三：我的行程，通知面板展开

```text
画布 1440×900，保留当前我的行程页面。
主标题“我的行程”，手写风副标题“把想去的远方，收进一本本旅行手册。”
保留搜索工具栏：输入提示“搜索行程名称或目的地”、目的地筛选“全部目的地”、排序“最近更新”；其他排序选项为“最近创建”“行程名称”，下拉未展开时不全部显示。
下方为现有旅行手册卡片网格。每张卡片左侧是带书脊、装订细节、城市地标插画、城市名与天数的封面，右侧是行程标题、目的地、活动数量、更新时间和“翻开行程 →”。沿用参考界面的真实内容与封面，不改成照片置顶的旅游商品卡片。
顶部“我的行程”选中。杭州任务已完成，生成入口收起，铃铛右上角显示小红点。
铃铛下方展开约 360px 宽的白色圆角通知面板，无全屏遮罩。顶部“通知”与“全部已读”。
第一条未读：“杭州 3 天行程已生成”“刚刚”“查看行程 →”，有未读点与轻微底色。
第二条已读：“北京 4 天行程已生成”“昨天”“查看行程 →”。
保持列表原有搜索、筛选和卡片布局；不新增统计、分类标签页或营销内容。
```

## 场景四：行程详情，收到另一份行程的完成提醒

```text
画布 1440×900，用户正在查看已有北京行程，杭州行程刚在后台生成完成。
保留当前详情页结构：全局导航下方为行程标题、日期、历史版本与导出操作；主体三栏分别为左侧旅行助手对话、中间行程总览或每日安排、右侧路线地图。
中间保留“总览”与每日切换；地图保留地点标记和路线。对话内容、景点和行程标题沿用参考界面。
顶部“我的行程”选中，铃铛右上角有小红点，通知面板关闭，生成入口已收起。
右上角、全局导航下方显示小型完成提醒：“杭州 3 天行程已生成”“路线与每日安排已准备好。”，含“查看行程”操作和关闭图标。
页面仍然显示北京行程，不自动切成杭州，不用全屏遮罩或成功庆祝大弹窗。突出提醒可点击，同时保持原有对话、行程与地图可见。
```

## 手机适配追加词

```text
将选定场景适配到 390×844。
顶部保留 Logo、首页、我的行程、铃铛图标和退出图标；生成状态有值时放在导航下方第二行。
首页沿用中国地图和纵向排列的四段规划胶囊；我的行程沿用搜索、目的地筛选、排序和单列书脊卡片；生成页将三阶段与拍立得区域上下排列。
详情页使用产品已有的“对话 / 行程 / 地图”切换，不将三栏强行压缩到手机上。它属于详情页内部切换，不是新加的全站底部导航。
若选定通知展开场景，通知以底部抽屉展示，保留关闭操作、全部已读和消息列表。
```
