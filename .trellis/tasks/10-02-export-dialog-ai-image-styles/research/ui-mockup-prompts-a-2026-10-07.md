## 使用方法

三份提示词均可独立复制，每次只生成一张、一个状态。先用第一份确定桌面视觉，再把满意的桌面初始稿作为参考图输入第二、第三份，以保持跨图一致。尺寸为设计目标，不是模型 API 参数。

PDF 横条统一文案「PDF 行程文档」「完整行程，方便保存」「另存为 PDF」，不在本次图片稿中承诺直接下载机制。当前代码仍调用打印对话框；实施时如果该机制尚未替换，说明必须使用「打印或另存为 PDF」。

## 1. 桌面初始态

```text
为中文旅行规划产品「织程 TripWeaver」设计一张精致、可信、可实际开发的桌面端导出弹窗 UI 截图。只输出一张完整界面，画布约 1440×1000。背景是轻微虚化的旅行行程页，可隐约看到行程列表和地图，覆盖柔和深色半透明蒙层；中央白色弹窗是画面焦点。采用「紧凑海报画廊」布局。

视觉：品牌蓝 #2F6BF3，主文字深藏青 #16325C，次文字 #5B6B86，浅蓝白背景 #EEF3FD，白色卡面 #FFFFFF，细描边 #DDE4E9。品牌蓝集中用于主按钮、选中卡细描边和小对勾。弹窗宽约 560px、高约 700px、内边距 24px、圆角 20px、轻柔投影；卡片和按钮圆角 12px。中文字体使用苹方或思源黑体，标题约 22px、正文 14–16px、辅助说明 12–13px。留白有节奏，以海报作品为视觉中心。

从上到下严格按以下结构：
1. 左上标题「导出行程」，下一行「杭州春日漫游 · 3 天」，右上细线关闭图标，图标周围留有足够点击空间。
2. 一条约 56–60px 高的轻量 PDF 横条，极淡蓝底。左侧简洁文件线性图标，中间「PDF 行程文档」和小字「完整行程，方便保存」，右侧低强调的文字操作「另存为 PDF」。整体干净克制，不做成大功能卡。
3. 区块标题「制作旅行海报」，旁边小字「AI 生成」，右侧辅助文字「风格示例」。
4. 两张等宽风格卡并排，间距 16px。每张上方是约 240px 高的浅色展示区，其中完整、等比例展示一张 2:3 竖版海报；下方是独立的白色文字说明区。2:3 是海报比例，不是整个卡片的比例。两张海报均用「杭州三日」作示例，海报本身文字少而清楚，重点是图像风格差异。
左卡为旅行手账插画：奶白纸底、湖蓝与暖橙点缀、西湖与小桥和塔的清新插画、少量手账路线元素。图下标题「旅行手账插画」，副文案「清新插画 · 记录旅途」。该卡被选中，外框有细品牌蓝描边，图下标题右侧一个小蓝色对勾。
右卡为水墨写意：宣纸底、淡墨远山、西湖水面和塔的写意线描、大面积留白、少量青绿及朱红点缀。图下标题「水墨写意」，副文案「水墨留白 · 东方意境」。该卡未选中，外框为浅灰细线。
5. 两张卡下面直接放一个宽度与内容区对齐、高 48px 的品牌蓝主按钮「生成分享图」，下面居中一行小字「通常需要 1–3 分钟」。

这是未生成状态。卡片下方没有空结果框、加载图标或成品预览；没有下载和重新生成按钮。风格标题和说明全部在图下，不压在海报上；不添加黑色贴片、底部暗色渐变、额外圆形 radio 或重复对勾。不添加会员、配额、分享链接或协作入口。不要手机外壳、浏览器地址栏、尺寸标注、拼图、3D 装饰、霓虹和大面积渐变。界面完整展示，底部按钮不能被裁掉。
```

## 2. 桌面已生成态

```text
为中文旅行规划产品「织程 TripWeaver」生成一张导出弹窗「已生成海报」状态的高保真桌面 UI 截图。只输出这一张界面，画布约 1440×1000。使用「紧凑海报画廊」设计：白色居中弹窗宽约 560px、高约 700px、内边距 24px、圆角 20px、轻柔投影；背景是行程列表和地图，轻微虚化并覆盖深色半透明蒙层。若提供初始态参考图，保持相同的弹窗外观、头部和 PDF 横条位置。

固定配色：品牌蓝 #2F6BF3，主文字 #16325C，次文字 #5B6B86，浅蓝白背景 #EEF3FD，卡面 #FFFFFF，细描边 #DDE4E9。中文使用苹方或思源黑体，标题约 22px、正文 14–16px、说明 12–13px。卡片和按钮圆角 12px，控件风格清晰克制。

顶部左侧「导出行程」，下一行「杭州春日漫游 · 3 天」，右上细线关闭图标。下方保留轻量 PDF 横条：文件线性图标、标题「PDF 行程文档」、小字「完整行程，方便保存」、右侧低强调操作「另存为 PDF」。

主体标题「旅行海报已生成」。原来的两张风格卡在这个状态被一张完整成品取代，同一主体区域中央展示约 208×312px 的 2:3 海报，四边完整、不裁切，周围有适量浅色留白。海报为清新旅行手账插画：奶白纸底、湖蓝与暖橙点缀，标题「杭州春日漫游」，小字「3 天」，西湖、小桥和塔的插画以及简洁路线元素，右下角小字「AI 创作 · 织程」。海报下方轻量文字「点击查看大图」。

在成品下方一行展示当前风格「旅行手账插画」，右侧文字操作「更换风格」。底部同一行放两个按钮：左侧较窄白底描边「重新生成」，右侧较宽品牌蓝实心「下载图片」，高均为 48px。按钮下用一行小字「AI 图片用于灵感分享，出行请以行程详情为准」。

视觉重点是已经生成的作品与下载操作。不要再显示两张选择卡，不要把成品追加到选择卡下面；不要显示生成耗时、旋转加载、进度条、「生成中」或「生成分享图」。不添加底部关闭按钮、配额、二维码、分享链接和社交平台图标。整张弹窗及所有操作完整可见。不要浏览器地址栏、手机外壳、尺寸标注、拼图、霓虹或大面积渐变。
```

## 3. 手机初始态

```text
为中文旅行规划产品「织程 TripWeaver」设计一张 390×844 比例的手机界面截图，展示「导出行程」弹窗未生成状态。只输出一张竖版 UI 截图。采用「紧凑海报画廊」，手机端是四角圆润的居中浮层，左右各留约 16px，弹窗上下均能看到蒙层，不贴底、不做底部抽屉。背景隐约是旅行行程页，使用柔和深色半透明蒙层。

视觉与桌面统一：品牌蓝 #2F6BF3、主文字 #16325C、次文字 #5B6B86、浅蓝白 #EEF3FD、白色卡面 #FFFFFF、细描边 #DDE4E9。弹窗宽约 358px，内边距 20px，圆角 20px；卡片和按钮圆角 12px，轻柔阴影。中文字体用苹方或思源黑体，标题 20px、风格名和主要文案 14–16px、辅助文字至少 12px，不能通过把文字缩得很小来塞满内容。若提供桌面参考图，保持同一套字体、选中态和配色。

由上到下：标题「导出行程」，下一行「杭州春日漫游 · 3 天」，右上角关闭图标。下方是一条紧凑、约 56px 高的 PDF 入口，浅蓝白底，左侧小文件图标和「PDF 行程文档」，右侧文字操作「另存为 PDF」；手机省去该横条的副说明以避免拥挤。

接下来是标题「制作旅行海报」，旁边小字「AI 生成」，下一行小字「风格示例」。两张风格卡仍然并排，间距约 12px，每张宽约 153px。卡片上方完整展示一张 2:3 竖版海报，等比例缩放，四周不裁切。下方是独立的白色说明区，风格标题和副文案不压在图上。
左卡：奶白底、湖蓝和暖橙的杭州旅行手账插画，图下名称「旅行手账插画」，副文案「清新插画」。左卡细品牌蓝描边，图下名称旁一个小对勾，表示选中。
右卡：宣纸底、淡墨西湖远山、淡青绿和朱红点缀的水墨海报，图下名称「水墨写意」，副文案「水墨留白」。右卡浅灰细描边，未选中。

两张卡片下方直接放通栏品牌蓝按钮「生成分享图」，高 48px；下方居中小字「通常需要 1–3 分钟」。所有内容在这个 390×844 画面中完整可见，按钮保留舒适底部留白。不要额外空预览框，不要把两张卡改成上下排列，不要添加生成结果、下载按钮或底部关闭按钮。不要黑色叠字标签、重复 radio、手机外壳、尺寸标注、浏览器工具栏、拼图、3D 装饰和大面积渐变。
```

## 4. 生成中状态修改词（配桌面初始稿使用）

此段是编辑指令，需要同时提供第一份提示词生成的桌面初始态图片。

```text
基于这张「织程」导出弹窗参考图，只修改海报主体区域和底部操作，制作同一个弹窗的「生成中」状态。保持外部背景、弹窗尺寸、标题、行程信息和 PDF 横条不变。

在原来两张风格卡占据的区域，居中展示已选的旅行手账风格小样，明确标注「所选风格」，下面是简洁的品牌蓝加载环、主文字「正在绘制你的旅行海报」以及小字「通常需要 1–3 分钟」。小样只代表风格，不是假装已经生成的结果。布局保持舒展，不额外增加一个结果框。

底部主按钮改为浅蓝禁用态「生成中…」，旁边提供低强调的「稍后查看」文字操作，右上角关闭按钮仍存在。原按钮下面重复的耗时说明移除。不要百分比、假阶段、倒计时或下载、重新生成按钮。保持所有文案、控件和留白清楚可读。
```

## 检查要点

- 配色在三张稿中一致，UI 主色为品牌蓝；海报作品内部可以有湖蓝、暖橙、青绿和朱红。
- 2:3 指海报内容，不把图下标题和说明强塞进 2:3 卡片。
- 初始稿仅有风格示例，完成稿仅有成品；两者不会上下堆叠。
- 手机是居中弹窗，底部按钮完整可见，文字不被截断。
- 每张稿只表达自己的状态，不同时出现生成中和可下载。
- 生图稿用于视觉讨论，中文字、对比度、焦点和交互仍需在实施时验证。
