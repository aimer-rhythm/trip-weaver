# 导出弹窗 UI 稿提示词（gpt-image）

用途：喂给 gpt-image / 其他 UI 生图模型，产出导出弹窗的高保真 UI 设计稿。
注意：本文件只是提示词与设计说明，不代表已实现的功能。

## 通用前置约束（每个提示词都加这段）

```text
一张高保真 UI 设计稿截图，扁平现代 SaaS 风格。不要 3D 元素、不要夸张投影、不要手机外壳、不要浏览器地址栏、不要标注线和尺寸数字。界面语言为简体中文，字体思源黑体或苹方，字号层级清晰。
配色：页面背景奶白 #FAF8F5，主色青绿 #2D6252，正文深灰 #2B2B2B，次级文字灰 #8A8A8A，卡片白色 #FFFFFF，描边 1px 浅灰 #E8E4DE，圆角 12–16px，按钮圆角 8px。留白充足，不用霓虹色、不用大面积渐变、不用发光效果。
```

## 1. 桌面版 · 初始态（默认选中手账插画，未生成）

```text
画面正中是一个白色弹窗，宽约 760px，圆角 16px，顶部标题栏左对齐标题「导出行程」，右上角一个细线「×」关闭按钮。
弹窗内纵向两个区块，中间用 1px 浅灰分隔线分开。
区块一：左侧标题「PDF 导出」，下方一行灰色小字「A4 排版，含每日路线与小贴士，可直接打印」；右侧一个青绿实心按钮「下载 PDF」。
区块二：标题「AI 行程分享图」，下方灰色小字「选择一种风格，生成适合分享的旅行海报」。标题下方两张并排的风格选择卡片，每张约 300×220px，卡片内上半部是竖版海报缩略图，下半部居中显示风格名。
左卡风格名「旅行手账插画」，缩略图是奶白底色、湖蓝与暖橙点缀的清新旅行插画，有纸张质感；这张卡为选中态：青绿 2px 描边，右上角一个青绿圆形对勾角标。
右卡风格名「水墨写意」，缩略图是宣纸米色底、水墨远山、大面积留白、淡青绿点染；这张卡为未选中态：1px 浅灰描边。
两张卡片下方居中一个青绿实心按钮「生成分享图」。
弹窗底部右侧一个浅灰描边的次要按钮「关闭」。
```

## 使用提示

- 中文文字在生图模型里容易出错。若标题或按钮文字出现错字、乱码，两个办法：一是把文案换成等长英文再出图，只用于看版式；二是在提示词末尾追加「图中所有文字用细灰色横线占位，不要渲染任何字母和汉字」，拿到干净版式稿后再用设计工具补文案。
- 需要更贴近现有产品观感时，把 `.trellis/spec/web/frontend/component-guidelines.md` 里的中文字体（演示悠然小楷只用于标题、正文用思源黑体）写进提示词，但字体会进一步降低文字正确率，建议只用于无文字版本。
- 缩略图里的海报示例不需要真实还原，只要让人一眼分出手账插画与水墨写意两种气质。
