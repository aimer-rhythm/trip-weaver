## 从参考图提取的结构

- 白色圆角弹窗，左上标题、右上关闭；顶部浅灰快捷操作卡，线性图标。
- 中部「分享图片（由 AI 生成）」标题，下方两张大预览卡并排。
- 风格名放在卡片顶部独立横向色条内，色条属于卡片的一部分，不是压在海报上的小标签。
- 选中卡：彩色标题条、同色细描边、标题条右侧圆圈对勾。未选中卡：中性标题条、空心圆。
- 底部一个居中的胶囊主按钮，下面一行辅助说明。

## 映射到织程

| 参考图 | 本版设计 |
| --- | --- |
| 四个快捷能力 | 顶部一张浅灰 PDF 快捷操作卡，横向布局；不扩展未实现的复制链接、协作与 Word 能力 |
| 路线手帐版 / 攻略卡片版 | 旅行手账插画 / 水墨写意 |

| 带口令码分享、每日剩余次数 | 不显示；现有产品无此能力，按钮下使用生成耗时 |
| 生成图片并保存 | 生成分享图；完成后原位显示成品并提供下载，不承诺自动保存 |

桌面约 680px 宽，内边距 24px，双卡间距 24px。卡片顶部色条约 30px，内部完整展示 2:3 海报，主体展示区约 360px 高，卡片外框不强制 2:3。弹窗总高约 800px；尺寸为构图目标，实际按视口适配。手机仍为居中弹窗，双卡缩放并排。

PDF 稿使用「导出 PDF」和「另存为 PDF」；当前实现仍打开打印对话框，实施时应继续准确提示「打印或另存为 PDF」，不能把视觉稿当作真实 PDF 下载已完成的证据。

## 使用方法

先把用户指定的原始截图作为参考图片附给生图工具，再使用第一份提示词。图片路径本身不能让外部生图模型读取本地文件。第二、第三份可配合第一份生成的满意稿作为参考，分别出图，不把多个状态拼在一张图里。
