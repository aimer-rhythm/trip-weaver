# AI 行程分享图导出

## 目标与已确认

将详情页原有长图 PNG 导出替换为 AI 生图，内置适合社交平台的行程分享提示词。用户指定第三方 OpenAI 兼容接口 `https://xjbh.lol/v1`、模型 `gpt-image2.5`，没有服务商文档，按 `POST /images/generations` 集成。不修改模型标识。

## 实现范围

- 站点独立配置 IMAGE_API_BASE_URL、IMAGE_API_KEY、IMAGE_MODEL；密钥只保存在服务端，不复用其他服务的凭据。
- 详情页导出菜单提供“AI 分享图”；打开统一 Modal，显式点击生成。默认1024×1536竖版，中文旅行插画海报，提炼每日路线与核心景点，不承诺完整行程或真实地图。
- 内置服务端提示词：实际目的地、标题、按日活动名称；文字清晰、排版留白、忠实给定行程、不虚构预约/票价、无第三方水印；角标“AI 创作 · 织程”。不发送住宿、私人备注、精确日期、地址、坐标及原始来源链接。
- 生成只在用户点击后调用；加载状态可见，防止重复付费请求。相同用户相同行程短时缓存与进行中请求去重；失败不自动重试，用户手动重试。
- 生成后预览、下载图片；微信支持长按保存。关闭弹窗不丢弃正在生成的结果；切换行程隔离状态。
- JSON备份与打印/PDF保留。
- 服务端认证与行程归属检查后才允许调用，支持当前草稿快照；接口超时、响应大小限制、敏感日志屏蔽、返回图片类型验证、外部图片URL SSRF校验。

## 验收

- [x] OpenAI Images兼容请求正确发送指定模型，支持b64_json及URL图片响应。
- [x] 无密钥时显示明确提示；401/404、忙碌、上游失败、超时和非法图片受控处理。
- [x] 提示词忠实行程且排除私人字段；缓存/去重避免重复生图。
- [x] UI复用Button、Modal、Dropdown，加载/失败重试/预览/下载与移动端验证。
- [x] 类型检查、构建、7项单测、API/浏览器验证通过；文档和规格同步。

验证均使用模拟上游；本地已配置地址和模型，IMAGE_API_KEY留空。截图在临时目录 tripweaver-share-image，含桌面失败态与手机版预览测试图片。内置浏览器不可用，使用独立Playwright完成验证。旧截图依赖html-to-image已移除。

## 边界

本次不自动向社交平台发布；不自动付费测试；服务商真实兼容性需配置独立密钥后才能验证。长行程采用摘要海报，不保证生图模型逐字排版。暂不增加个人BYOK设置和图片历史管理。

## 调研

当前入口 `apps/web/src/components/ExportMenu.tsx` 使用 html-to-image 生成长图，PrintView保留用于打印。TripEditorPage提供当前草稿。官方接口参考 https://developers.openai.com/api/docs/guides/image-generation ，仅用于协议参考，第三方模型名按用户配置保留。
