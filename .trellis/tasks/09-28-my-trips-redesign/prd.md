# 我的行程页面功能与视觉重设计

## 目标

将现有管理按钮密集的列表改为旅行手册式行程收藏页，方便用户查找和打开已有行程。用户确认选择「旅行手册式卡片」，接受搜索、目的地筛选、排序和整卡进入详情的方向。

## 已确认需求

- 移除导入JSON、新建行程、重命名和删除入口。
- 采用旅行手册式卡片，延续全站蓝青淡紫背景、磨砂玻璃和轻盈阴影。
- 保留搜索、目的地筛选和排序，整张卡片点击进入行程详情。

## 实施默认值

- 搜索匹配行程标题及目的地；目的地筛选来自现有行程数据。
- 默认最近更新排序，另提供最近创建和名称排序。
- 搜索、筛选、排序保存在URL参数，打开详情后返回可恢复列表条件。
- 页面不提供示例行程导入或列表JSON导出；导出统一使用详情页完整导出入口。
- 空列表展示友好说明，提示通过顶部品牌返回首页规划，不再添加新建按钮。
- 搜索无结果可清除筛选；请求失败展示重试；加载态展示骨架。
- 不添加收藏、置顶、归档、已出行/待出行等需要新数据模型的状态。

## 数据与设计边界

- 当前TripListItem提供标题、目的地、天数、活动数、创建时间、更新时间和版本号，不提供照片、出发日期或人员数。
- 不为每张卡逐条请求详情，不伪造旅行日期，不把更新时间当作出发时间。
- 卡片以居中的目的地手写字、淡色书封和书脊呈现，不使用手绘图，不依赖不存在的封面图。
- 主标题宋体，目的地手写体，正文无衬线。主要信息真实、可读；版本号不作为主视觉。
- 桌面3列，平板2列，手机1列。页面可自然滚动，与固定视口的详情页区分。

## 验收

- [x] 无导入JSON、新建行程、重命名、删除及加载示例入口。
- [x] 搜索/目的地筛选/排序可组合，空结果和错误状态可恢复。
- [x] 整卡键盘可访问，进入详情后返回保留条件。
- [x] 长标题、多个目的地、空数据及小屏无横向溢出。
- [x] 类型检查、构建、浏览器验证通过。
