# 我的行程 UI 生图提示词

使用方式：将首页和行程详情页的 UI 图作为参考图一起上传给 GPT，再复制以下提示词。输出规格为 **1920 × 1080 像素，16:9 横屏**。

```text
请为旅行规划产品 TripWeaver 设计「我的行程」页面，生成一张高保真桌面端 UI 设计图。参考上传图片的品牌色、字体、背景和按钮风格，保持与首页、行程详情页属于同一套产品。

【画面规格】
1920 × 1080 像素，严格 16:9 横屏，正面完整网页界面，中文清晰可读。
这是可落地的产品页面设计，不是海报，不要设备外框、透视展示或多页面拼图。
按照此分辨率安排导航、标题、工具栏和两行卡片，所有主要内容完整显示，四周保留舒适留白，不裁切第二行卡片。

【设计方向】
将页面设计成「旅行手册收藏架」：安静、精致、有旅行记忆感。
使用浅蓝、淡青、浅紫渐变背景，半透明白色面板，细腻边框与柔和阴影。
卡片有纸张厚度和轻微立体感，但不要夸张拟物或强烈发光。

【顶部导航】
左侧 TripWeaver 品牌标识。
保留简洁的首页、我的行程导航，突出当前页面「我的行程」。
右侧为低调的账户入口。沿用参考图的导航视觉。

【标题区】
主标题：「我的行程」，使用优雅的中文宋体。
副标题：「把想去的远方，收进一本本旅行手册。」
副标题可使用参考图中生成中页面的中文手写字体，轻松自然。
辅助信息：「共 6 本旅行手册」，弱化显示。
留白舒展，不放巨大的装饰插画。

【查找工具栏】
标题区下方放置一条简洁工具栏：
1. 搜索框：搜索行程或目的地
2. 目的地筛选：全部目的地
3. 排序：最近更新
搜索框较宽，筛选和排序紧凑。
控件圆角、浅色半透明背景，文字对比清晰。
强调色直接沿用参考图首页「开始规划」按钮的蓝色，不另外引入橙色或绿色主题按钮。

【核心内容：旅行手册式卡片】
桌面端三列、两行，共六张卡片。内容居中，卡片尺寸和间距适配 1920 × 1080 画布，避免过度拉宽。
整张卡片可点击，进入对应行程详情。

每张卡片分为「书封区域」和「信息区域」：

书封区域：
- 使用淡蓝、鼠尾草绿、浅杏、雾紫等低饱和底色，整体和谐。
- 用较大的中文手写字体展示目的地名称。
- 加入极简路线虚线、小圆点或目的地线描，装饰克制。
- 左侧有细微书脊或装订线细节，产生旅行手册的感觉。
- 右上角放小型天数标签，例如「3 天」。
- 不使用景点照片，不做照片拼贴。
- 不添加与行程数据无关的日期、天气或人物信息。

信息区域：
- 行程名称清晰突出。
- 下方展示目的地和活动数量。
- 底部左侧展示明确标注的更新时间，右侧是轻量文字入口「翻开行程 →」。
- 信息区域保持统一高度与对齐。
- 卡片圆角适中，使用两层柔和阴影增加立体感。
- 不要在卡片内放置大面积实心操作按钮。

示例卡片内容：
1. 北京｜北京胡同与博物馆之旅｜3 天｜12 个活动
2. 杭州｜西湖边的慢生活｜2 天｜8 个活动
3. 成都｜成都街巷寻味记｜4 天｜16 个活动
4. 上海｜梧桐树下的城市漫游｜3 天｜11 个活动
5. 北京｜周末去看皇家园林｜2 天｜7 个活动
6. 大理｜苍山洱海放空计划｜5 天｜18 个活动

更新时间示例：「更新于 9 月 28 日」。
注意：这是更新时间，不是出发日期。

【字体与交互视觉】
中文宋体用于页面主标题。
中文手写字体仅用于副标题和书封上的目的地。
正文、筛选控件、行程名称和日期使用清晰的无衬线字体。
整卡应明显具有可点击感，可让第一张卡片呈现轻微悬浮和阴影加深的状态。
正文保证可读性，避免浅灰小字。

【明确不要出现】
不要导入 JSON。
不要新建行程按钮。
不要加载示例。
不要重命名、删除、更多菜单。
不要列表页导出按钮。
不要收藏、置顶、归档、已出行或待出行标签。
不要侧边栏、数据统计仪表盘或助手对话框。
不要英文占位文案、乱码、密集装饰和过度玻璃效果。

最终效果应像一处精心整理的个人旅行手册收藏空间，重点是快速查找已有行程，并自然地点击卡片继续查看。
```
