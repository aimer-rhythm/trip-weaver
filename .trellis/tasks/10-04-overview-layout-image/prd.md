# 优化详情总览层级并生成 UI 设计图

## 目标

按用户明确要求删除详情总览的「出行手册」「每日安排」标题，将旅行建议、注意事项移至行程卡上方；提供页面 UI 参考图及 GPT-image 设计图。

## 需求与实现范围

- 总览不再展示两处标题，不额外增加替代抬头；外层区域保留「行程总览」无障碍名称。
- 旅行建议和注意事项保留现有纯圆点列表、宽屏两栏和窄屏自适应，整体置于每日行程卡之前。
- 保留总站数提示、每日卡片手写标题、日期和天气、路线、添加一天、选日交互。
- 截取桌面、手机及聚焦总览的 UI 图，整理准确的图生图提示词。生图渠道以实际工具可用性为准，不把浏览器截图称为 GPT-image 输出。
- 用户已说明具体布局，本次不扩大到地图、对话面板或天气数据逻辑。
