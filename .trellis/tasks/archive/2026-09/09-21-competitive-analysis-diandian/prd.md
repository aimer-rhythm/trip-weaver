# 竞品与差异化分析：小红书点点等 AI 行程规划竞品

## 背景

PRD（docs/PRD.md v0.3）缺少竞品章节，且数据源描述已过期：
- 文档注记写的是「调研数据源 = 高德地点数据 + 全网搜索」（2026-07-09 决议）
- **现状（2026-09-21 更正）**：已放弃「全网搜索 + 高德」，原因是速度慢、内容质量差
- **当前方案**：抓取小红书笔记 → 清洗提纯入库 → 调研阶段做 RAG 检索召回

由此引出的核心问题：用户在小红书里搜攻略，点点（AI 问答）已经能总结笔记并给出行程安排，速度快、图文并茂。那么 TripWeaver 存在的意义与差异点是什么？

## 目标

产出一份可长期维护的竞品与差异化分析文档，回答「为什么这个项目值得做」，并把结论沉淀进 PRD。

## 产出物

1. 新增 `docs/COMPETITIVE_ANALYSIS.md`
   - 竞品矩阵（3–5 个竞品，对比维度统一）
   - **小红书点点专章**（重点）：能力边界、优势、劣势、对我们的挤压点
   - TripWeaver 差异化定位与护城河
   - 风险清单（时效性 / 覆盖度 / 合规 / 数据侧工程量）
2. 更新 `docs/PRD.md`
   - 修正数据源叙述为「小红书笔记 RAG 检索」
   - 增补「竞品与差异化」章节

## 范围

- **做**：竞品对比、定位论证、风险清单
- **不做**：产品功能改动、代码改动、定价策略

## 验收标准

- [ ] `docs/COMPETITIVE_ANALYSIS.md` 存在，含竞品矩阵 + 小红书点点专章
- [ ] 每个竞品结论都有可核验依据（官方功能说明 / 公开报道），不靠推测
- [ ] 明确指出 TripWeaver 的护城河与「什么情况下这个项目没有意义」
- [ ] `docs/PRD.md` 数据源叙述与现状一致，不再出现「全网搜索 + 高德」作为当前方案
- [ ] PRD 增补竞品章节并交叉引用分析文档
