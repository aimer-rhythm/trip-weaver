## 首次失败与修复

本次验证先有一次失败：任务 `d8992e81-a196-4f80-8f8d-f525b6984281`，6.663 秒，首轮输出 233 tokens，第二轮返回 HTTP 400 `inference request is invalid`，无新行程、不消耗成功生成额度。上述成功轮次表不包含这次失败。

原因与修复：生成模型只设了 DeepSeek thinking 格式，遗漏 SDK 官方 DeepSeek 模型配置中的 `requiresReasoningContentOnAssistantMessages`。关闭思考后，工具续轮也需要 assistant 消息的空 `reasoning_content` 占位。增加该兼容项并把原本仅覆盖单轮的 HTTP 测试改成「补查 → 提交」两轮测试；新测试与类型检查通过。真实续轮请求包含空字段后返回 200，完成生成。未知模型、命名空间别名和对话默认入口不改变。
