# 参考 UI 的第二轮手写字体对比（2026-09-30）

用户进一步给出详情页“沿着中轴线，走进老北京”和生成页相片下方的题字，允许更轻、细的手写风格。上一轮 B/C 尚未选定；本轮继续提供真实字体样张，不替换应用字体。

## 视觉建议

- **E 演示悠然小楷**：本轮最贴近两张参考的风格。细笔、有行楷笔锋，标题与照片题字都协调。截图不能证明原稿就是此字体。
- **G 悠哉字体**：更接近日常细笔手写，较少书法笔锋；适合手账照片说明，字库更广。
- **D 演示夏行楷**：笔锋更飘逸、字距疏朗，是偏行书的备选。
- F 沐瑶随心和 H 沐瑶软笔更圆润、活泼；I 江西拙楷更厚重，而且缺“簋”，不优先推荐。

## 交付与核验

- 对比页面：<http://127.0.0.1:18799/font-reference-comparison.html>，保留用户原图裁片与 D–I 六个候选，标题32px、照片题字22px；手机标题27px。原图裁片来自用户本地参考文件，照片只是参考图局部。
- 构建：`build-font-reference-comparison.py`；浏览器核验：`verify-font-reference-comparison.mjs`。
- Chrome 实际字体检查使用 CDP `CSS.getPlatformFontsForNode`，不是仅检查字体加载状态。六款标题均使用自定义字体；E/G 的标题、补充标题、相片题字和测试字均无系统回退；I 的“簋”真实回退。
- 桌面1500×1000、手机390×844截图；图片解码、页面异常与横向溢出检查。结果保存 `font-reference-result.json`，截图 `font-reference-desktop.png` / `font-reference-mobile.png`。
- 等待用户字体选择；本轮是研究与预览，没有提交、归档或标记任务完成。
