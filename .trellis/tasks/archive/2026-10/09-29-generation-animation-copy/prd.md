# 生成页动画与文案优化

## 目标
排查生成页间歇性动画，优化用户向进度文案，拍立得只显示景点名称。

## 范围与验收
- 检查首次进入、连续进度更新、同文案新事件、照片更新及减少动态效果。
- 动画与真实事件匹配，不因耗时刷新重播，也不因重复文案漏播新事件。
- 三阶段文案简洁，保留真实进度信息。
- 照片只保留名称，长名称可换行；桌面和移动端不截断、不遮挡操作区。
- 运行类型检查、前端构建、相关单元与浏览器回归。
- 实现与自测后交付用户验收，验收前不提交、不归档。

## 已知
- 当前 TypedStatus 以显示文字为 key，同文案不同事件无法重播。
- 当前照片 figure 以 id 为 key，同景点换照片不会重播入场。
- 当前说明为 name + intro 且强制单行省略。
- 不改服务端生成逻辑和用户其他未提交改动。

## 用户补充与已复现原因
- 用户确认主要问题是步骤呼吸光圈／整个页面。
- 服务端 review phase_end 后仍执行最终地理与路线复核、持久化；三个步骤全 done 时前端移除全部光圈。浏览器回归已复现 active halo = 0。
- 前端将全阶段结束但任务未终结的最后一步保留 active；等待首个阶段时显示准备状态。阶段协议和后端不变。
