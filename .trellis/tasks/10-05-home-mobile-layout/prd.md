# 优化首页移动端样式

## Goal
让手机用户容易看清、选择旅行条件并开始规划，保留首页地图与玻璃视觉风格。

## Requirements
- 2026-10-06 用户确认按下载目录参考 UI 图重做移动端：首屏直接规划，下方目的地精选；城市地图移入全屏选择界面。
- 顶部简化为标志、通知与账户入口；首页和行程列表的手机底部导航提供「首页 / 我的行程」。
- 目的地界面支持返回、地图点选、全部城市列表、城市预览和确认；确认才更新首页目的地，取消保留原选择。浏览器返回可关闭，其他草稿不丢失。
- 2026-10-06 用户调整：移除选择目的地顶部搜索框；手机地图固定为完整展示的比例，不可拖拽或缩放，隐藏右下角工具组，继续支持点选城市和纵向页面滚动；精选卡片选中只保留边框高亮，不显示勾号。
- 目的地精选只取知识库已覆盖城市，真实图片本地存储并记录来源；图片缺失降级为现有城市插画或占位。
- 2026-10-06 用户指定复用现有已审核图库：静态精选优先北京、杭州、厦门，沿用既有采用门槛与用户排除记录，核对本地字节摘要，不新增外部搜索或审图。
- 卡片使用乳白玻璃背景、细分隔线、彩色图标和右箭头；主按钮显示「生成我的行程」，缺少条件时有可见说明。
- 标题、摘要、触控区域使用适合手机的尺寸，开始规划显示明确文字。
- 日期、节奏与同行、偏好保留共享 Modal 底部弹层；目的地复用 Modal 的全屏样式。
- 保留桌面地图、横向胶囊及浮层布局，保留所有登录、生成、账号草稿语义。
- 考虑 320px 小屏、横屏、平板、长摘要、城市列表、加载失败与空状态；地图不能阻止手机页面纵向滚动。

## Acceptance Criteria
- [ ] 参考图的首屏规划卡片、精选图片与底部导航落实，无横向溢出和遮挡。
- [ ] 无顶部搜索框；手机地图完整展示，拖动/缩放不改变地图且无工具组，城市点选正常；精选选中无勾号。
- [ ] 全部城市列表、地图点选、预览、确认和取消/浏览器返回正确，未覆盖城市不出现。
- [ ] 日期/节奏/偏好草稿在选择城市和返回后保留，生成参数与账号隔离保持正确。
- [ ] 320 / 375 / 390 / 768px、横屏及桌面验证，包含图片失效与空/错误状态。
- [ ] typecheck、构建与相关浏览器验证通过。
- [ ] 提供截图和预览，等待用户明确验收后再提交或归档。

## Technical Approach
HomePage 通过查询参数打开目的地选择，复用 ChinaMap；HomeCapsule 保持日期/节奏/偏好状态。新增 DestinationPicker 和目的地展示组件，扩展 Modal 的全屏样式；AppLayout 在首页/列表提供底部导航。浏览器采用本地 Playwright API fixtures，不调用真实生成服务。

## Out of Scope
不改变生成逻辑、后端接口、桌面整体设计，不提交/归档，不覆盖工作区既有专属建议等修改。
