# 高德路线支持切换交通方式并展示各方式时长

## 状态

2026-09-29 用户要求开始实施，并确认仅切换当前路段；重排后起终点未变的相邻路段保留选择。

## 需求

- 点击行程中相邻地点的交通信息，展开下拉菜单。
- 展示可用交通方式（步行、骑行、驾车、公交/地铁）的各自耗时；以高德实际支持的能力和查询结果为准。
- 选择交通方式后，同步当前路段的交通方式、时长及地图路线，并保存选择。
- 无结果、服务失败或尚未查询时使用明确状态，不把估算值冒充高德结果。

## 验收草案

- [x] 下拉显示当前方式和其他可用方式及耗时。
- [x] 切换后交通行、地图、保存数据保持一致。
- [x] 查询失败、不可达、快速连续切换有正确反馈，旧响应不覆盖新选择。

## 实施决策

- 在已鉴权且校验行程所有权的 POST /api/trips/:id/route-options 查询四种方式。传递编辑中的两个活动快照，允许自动保存前的坐标修改；服务端转换旧 WGS84 坐标。
- 当前天自动预查询各路段的四种方式，单方式请求串行调度，用户选择的请求优先。换天/卸载取消未开始的查询；不预取其他天。
- 浏览器共享缓存 5 分钟，返回当前天不重复请求；服务端按用户、凭据版本、坐标与模式缓存成功方案 5 分钟，短暂不可用结果 30 秒。命中服务缓存不重复扣编辑额度。
- 选择后自动应用所选方式的高德推荐方案；无缓存或过期时自动查询，成功后再更新路段与地图。最新选择优先，失败保留原路线。
- 路线菜单复用现有蓝色、浅色面板、14px 圆角及阴影，保留键盘/Escape/失焦关闭行为。
- 返回真实来源和不可用说明，不使用启发式补足选项。部分失败不影响成功方式；允许重试。
- 选择仅替换当前活动对的 leg，并走原有 revision 自动保存；地图读取同一 draft。请求返回和选择时检查活动对、坐标、行程身份，拒绝过期结果。
- 当前任务不触发移动后的自动重算，该流程由已有 09-28-replan-transit-after-move 接续；查询接口可复用。
- 公交折线需从 walking/bus segments 提取，缺失时明确保留地图连接线降级。
