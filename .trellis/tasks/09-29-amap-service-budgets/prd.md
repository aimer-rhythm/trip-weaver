# 高德分服务调用预算与限流日志

## 目标

将高德全站混合预算拆为实际服务预算，生成、编辑器、POI 图片复用同一请求前原子扣减，避免并发和重启绕过限额。补充安全日志，区分本地预算耗尽、高德拒绝、HTTP 错误与超时。

## 决策

- 按 geocode、place、walk、cycle、drive、transit 六项配置每日上限；POI 定位与图片共用 place。
- 个人认证、无流量包，按官方月配额计算且不扣当前已用量：五项 LBS 共享150000/月，POI搜索5000/月；按31天均分得到五项各967/日、搜索161/日。
- 月预算可配置，各服务日值可覆盖但总和不能超出所属组月预算/31。旧 AMAP_DAILY_BUDGET 只压低未独立配置服务的默认值；0 禁用，非法值拒绝启动。
- PostgreSQL 持久计数，在真实 fetch 之前原子占用；缓存命中不扣，发出后即使失败也不退，数据库异常拒绝外呼。
- 日界使用 Asia/Shanghai（UTC+8），与高德日额度对齐；保留现有串行请求间隔和任务级防滥用上限。
- 六项全站共用（含个人 Key），采取保守计数；无法控制同 Key 的站外调用或高德其他共享/月度配额。
- 移除旧的高德混合预算阻断，天地图现有计量不变。旧 generations.amap_calls 继续作为任务尝试统计，不再当作新限额账本。
- 首次升级保守将近期旧统计计入各服务，避免部署当天清零造成超量；使用全新数据库从零开始。
- 输出服务名、used/limit、infocode/info 分类、HTTP 状态与耗时，不输出 Key、完整 URL、地址或坐标。

## 验收

- [x] 六项预算独立且同一服务的多个业务入口共用。
- [x] 并发请求不能超额，重启不清零，跨 UTC+8 零点正常重置。
- [x] 零额度、配置错误、数据库失败、缓存、上游错误路径验证。
- [x] API 权限、路线结果与生成降级行为不退化。
- [x] 配置示例、日志查看方法、数据库查询方式和迁移边界有文档。
